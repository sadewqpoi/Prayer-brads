# مسباح   

متجر عربي RTL مبني باستخدام HTML وCSS وJavaScript عادي، ويخزن منتجاته وسلته وطلباته في localStorage.

## التشغيل على الكمبيوتر

1. فك ضغط المشروع أو أنشئ مجلد `mesbaah-store`.
2. أنشئ داخله `index.html` ومجلدي `css` و`js`.
3. انسخ الملفات إلى المسارات الموضحة.
4. افتح `index.html` في المتصفح.

للتطوير المحلي، يمكنك تشغيل خادم بسيط من مجلد المشروع:

    python -m http.server 8000

ثم افتح `http://localhost:8000`.

## لوحة الإدارة

افتح الرابط `#admin` من الموقع. كلمة المرور التجريبية هي `mesbah-demo`.
هذه كلمة مرور للعرض فقط؛ لا توفر حماية فعلية، ولا ينبغي نشرها على أنها نظام دخول آمن.

## التخزين التجريبي

البيانات محفوظة في localStorage على الجهاز والمتصفح الحاليين. حذف بيانات الموقع من المتصفح قد يحذف المنتجات والطلبات. صور المنتجات المحلية محدودة الحجم لتفادي امتلاء التخزين؛ استخدم روابط صور أو خدمة تخزين صور في الإنتاج.

## ما يلزم قبل البيع الفعلي

- خادم API وقاعدة بيانات لإدارة الحسابات والمنتجات والمخزون والطلبات.
- تسجيل دخول وصلاحيات إدارة آمنة من جهة الخادم، مع تخزين كلمات المرور بطريقة آمنة.
- بوابة دفع معتمدة وتكامل خادمي للتحقق من عمليات الدفع. خيارات الدفع في الواجهة لا تنفذ معاملات مالية.
- خدمة شحن للحصول على الأسعار وإنشاء الشحنات وتحديث التتبع.
- استضافة HTTPS، نسخ احتياطي، ومراقبة للأخطاء.
- سياسة خصوصية واستبدال واسترجاع نهائية ومناسبة لنشاط المتجر.

لا ترسل بيانات البطاقات إلى هذا النموذج أو تخزنها في المتصفح.
